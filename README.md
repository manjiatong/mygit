# AI Learning

Mike 的学习笔记与代码练习仓库。

## 目录说明

- `python/` — Python 课程练习代码（ENGG1330 等）
- 所有课程敏感材料（试卷、答案、讲义 PDF 等）— **不提交到 git**
- `vscode/` — VSCode 使用与配置笔记

## 使用约定

- 每次提交保持小而专注
- 课程敏感资料（试卷、答案）请放在本地或单独的私有仓库
- 文件名建议用英文或拼音，避免中文文件名（终端显示会乱码）

## 常用命令

```bash
git status          # 查看当前改动
git add <file>      # 添加指定文件
git commit -m "msg" # 提交
git log --oneline   # 查看历史
```
